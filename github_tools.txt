    This tool intentionally aggregates 6 issue write endpoints under one tool
    so the LLM picks an *intent* (close, comment, ...) instead of one of N

    optional parameters; unrelated parameters are ignored.
    
    Args:
        owner: Repo owner.
        repo: Repo name.
        number: Issue number.
        action: One of:
            - ``"edit"`` — uses ``title`` and/or ``body``. At least one required.
            - ``"close"`` — closes the issue. Optional ``state_reason``:
              ``"completed"`` (default) or ``"not_planned"``.
            - ``"reopen"`` — reopens the issue. No other params.
            - ``"comment"`` — adds a conversation comment. Requires

            - ``"set_assignees"`` — **replaces the full assignee set** by
              diffing against the current state. ``assignees`` is a
              comma-separated list of GitHub logins (empty string clears).
        title: For ``action="edit"``.
        body: For ``action="edit"``.
        state_reason: For ``action="close"``.
        comment_body: For ``action="comment"``.
        labels: For ``action="set_labels"``.
        assignees: For ``action="set_assignees"``.
        user_login: Leave empty to auto-detect the workspace credential.
    
    Returns:
        Success — JSON containing the action taken plus the projected issue
        (or comment, for ``action="comment"``).
    
        Failure — single-line error with action suggestion.
    meta: toolkit=github, toolkit_service=repos

  review_github_pull_request
    Submit a review event or merge a pull request.
    
    These actions are kept apart from ``update_github_pull_request`` because
    they are not property edits — a review is an immutable event in the PR
    timeline, and a merge is destructive (cannot be undone via the API).
    
    Args:
        owner: Repo owner.
        repo: Repo name.
        number: PR number.
        action: One of:
            - ``"approve"`` — submit an approving review. ``body`` optional.
            - ``"request_changes"`` — submit a changes-requested review.
              ``body`` is **required** by GitHub and validated here.
            - ``"comment"`` — submit a non-blocking review comment. ``body``
              is **required** when there are no ``line_comments``.
            - ``"merge"`` — merge the PR. Uses ``merge_method`` /
              ``commit_title`` / ``commit_message`` / ``sha``.
        body: Review body markdown. Semantics depend on ``action``; see above.
        line_comments: Optional line-level comments for the review, each
            shaped ``{"path": ..., "line": ..., "side": "RIGHT"|"LEFT",
            "body": ...}``. Only applies to review actions, not ``"merge"``.
        commit_id: Optional SHA the review should anchor to. Defaults to PR head.
        merge_method: For ``action="merge"``: ``"merge"`` (default) /
            ``"squash"`` / ``"rebase"``.
        commit_title: For ``action="merge"``. Optional.
        commit_message: For ``action="merge"``. Optional.
        sha: For ``action="merge"``. If set, GitHub rejects the merge unless
            the PR head still matches this SHA — defends against merging a
            stale branch.
        user_login: Leave empty to auto-detect the workspace credential.
    
    Returns:
        Success — JSON containing the action taken plus the relevant payload
        (review object for review actions, merge result for merge).
    
        Failure — single-line error with action suggestion.
    meta: toolkit=github, toolkit_service=repos
      - owner (string) (required)

    The enabled Composio apps are controlled by server config. By default,
    only Instagram is enabled.

      is not required for Accio-managed Composio Instagram tools.
    - Before asking the user to authorize again, call COMPOSIO_CHECK_ACTIVE_CONNECTION
      with toolkit="instagram". If it returns ACTIVE, continue with Instagram MCP
      publish/media tools instead of opening Instagram in a browser.
    - For Instagram tools that require ig_user_id, use "me" unless the user
      provided a specific Instagram Business Account ID. Do not use Composio
      connected_account_id values such as "ca_*" as ig_user_id.
    - Only call this tool when no ACTIVE Instagram connection exists or when the
      user explicitly asks to reconnect / re-authorize.
    
    Args:
        app_name: The name of the app to connect, e.g. "instagram" or "ins".
        intent: Reserved for desktop client use; do not set this argument from a

            already has a healthy ACTIVE connection it is reused without asking
            the user to authorize again.
    meta: toolkit=composio, toolkit_service=admin
      - app_name (string) (required)
